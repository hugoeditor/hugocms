## Description

This page's meta description is well over about 160 characters. Google truncates
the preview text (…), so the end – often the call to action – is lost.

## Why it matters

- The most important part (benefit, prompt) should sit before the truncation
  point.
- Overly long text looks cluttered in the result.

## How to fix it

Shorten the description to **120–160 characters**. One sentence about the content
plus a short call to action is enough. Put the most important part first.
