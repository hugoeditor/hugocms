## Description

This meta description appears word-for-word on several pages. That weakens each
page, because the same preview text shows up repeatedly in the search results.

## Why it matters

- Identical descriptions look mass-produced and reduce the click-through rate.
- Search engines favour pages with distinct, fitting text.

## How to fix it

Write a **distinct** description for each page that reflects its specific content.
For pages generated from data, put the distinguishing value (model, location,
service) into the description instead of one fixed template for all.
